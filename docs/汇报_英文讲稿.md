# ORCA Hand 进度汇报 · 英文讲稿

2026-11-12 写，给美国领导做口头汇报用。在线版（可编辑）：<https://claude.ai/artifact/PvyL84rrj9ZknVC1bwD1By>

## 怎么用

讲稿约 3 分钟、400 词左右。顺序按美国职场最常见的“先说结论”：结论 → 已完成 → 遇到的问题 → 正在做的 → 下一步和需要的支持。这是主流做法，领导第一句就知道整体状态。

方括号 [ ] 里的内容要按汇报当天的实际情况修改。句子都写得很短，方便开口说。练习时大声读 2–3 遍并计时，不用背全文，记住每段的第一句就能往下接。

要注意区分实测和理论：“5 ms 一轮”是按 1 Mbps 算出来的理论值，还没有实测过，汇报时不要说成实测结果。两块板的方案也还没上真手测试，讲稿里同样说清楚了。

## 讲稿

### ① 先说结论（约 20 秒）

Good morning, [name]. Let me give you a quick update on the ORCA hand.

The short version: the hand is fully assembled and calibrated, and it runs all the basic gestures. It also works with our own board, the KM1M7C, instead of the official U2D2. Right now, I'm splitting the control across several boards, one per finger.

### ② 已完成的工作（约 50 秒）

Here's what's done so far.

First, assembly. It's the ORCA v2.0 left hand, with seventeen Dynamixel motors. I finished the assembly on October 30th and did the first calibration.

Second, tuning. By November 4th, I had pre-tensioned the tendons and calibrated again. The neutral pose, the zero pose and the gesture tests all passed.

Third, the controller. On the same day, I replaced the U2D2 with our KM1M7C board. It runs a simple pass-through firmware that I wrote, so the official ORCA software works with it. I also raised the bus speed from 57,600 baud to 1 megabit per second.

### ③ 遇到的问题和经验（约 30 秒）

We had one problem along the way. During a full-range test, a tendon knot on the middle finger pulled through its hole and got stuck inside the hand. I repaired it and re-installed the tendon, and it's fine now.

The lesson: always start with a small range and low current, then go to full range step by step.

### ④ 正在做的（约 50 秒）

What I'm working on now: the plan is six boards. That's one board for each finger, plus one shared by the wrist and one thumb motor.

As a first step, I have two boards running the same firmware. They show up as two separate COM ports on the PC. I added a small multi-bus layer to the ORCA software, so it can drive several boards as one hand. The code is ready, but I haven't tested it on the real hand yet. [如果汇报前已经测过，改成：I tested it on the real hand yesterday, and it works.]

Why split it up? At 1 megabit, speed is not the main issue. The main benefit is fault isolation: if one finger has a problem, the others keep working. It also prepares for the next stage, where each board can read sensors and adjust its own finger.

### ⑤ 下一步和需要的支持（约 30 秒）

Next steps.

One: test the two-board setup on the real hand, and measure the loop time.

Two: if that works, move to all six boards. That needs six level-shifter circuits and careful wiring for power and ground.

[目标时间，没把握就删掉这句：I'm aiming to finish the two-board test by ___.]

[需要支持就说，不需要就删掉：One thing I need is ___ .]

That's all from me. Any questions?

## 领导可能问的问题

下面的问题是按美国经理最常追问的方向推测的：能不能演示、为什么这样做、风险、时间、需要什么。回答都先给一句结论，再补充一两句。括号里的中文是提示，帮你在听到问题时认出它。

**1. Can you show me a demo?**（能演示一下吗）

Yes. With one board, I can run the neutral pose and the gestures right now. The two-board setup isn't tested on the hand yet, so today I'd show the one-board version.

**2. Why not just use the U2D2?**（为什么不直接用官方的 U2D2）

The U2D2 only connects the PC to the motors. With our own board, we can later run control on the board itself, using sensor data. It also lets us split the hand into several buses.

**3. Why six boards? Isn't one enough?**（为什么要 6 块板，1 块不够吗）

For speed, one is enough. The reasons are fault isolation, and getting ready for sensor control on each finger.

**4. How fast is the control loop?**（控制一轮多快）

In theory, about 5 milliseconds for all 17 motors on one bus. I haven't measured the real number yet. USB and Python will add some time, so I'll measure it in the two-board test.

**5. Did you change the official software?**（你改了官方软件吗）

Only a little. I added one new file and a few lines in two existing files. If the config doesn't say "multibus", it works exactly like the original. Because of this change, we should stay on the current version of the ORCA software for now.

**6. What are the risks?**（有什么风险）

Three things. First, several USB ports may add delay, and I need to measure that. Second, six boards means six level-shifter circuits and more wiring, so power and ground need care. Third, tendons can slip at full range, so I always start with low current.

**7. When will the six-board version be ready?**（六块板的版本什么时候能完成）

I'd like to finish the two-board test first. After that, I can give you a realistic date. [如果有大概的估计，可以加一句：My rough guess is ___.]

**8. Do you need anything from me?**（需要我帮什么忙吗）

[按实际情况填，比如更多调试时间、电平转换的零件、做 PCB 的预算。不需要就说：Not right now. I'll let you know if that changes.]

## 补充：按“实体 + 传感器”两部分介绍时用的句子

11-12 当天汇报改成了两部分：机械手实体和指尖传感器。下面是当天准备的句子。

| 场景 | 英文 | 备注 |
| --- | --- | --- |
| 开场 | Today I'd like to cover two things: first, the physical hand, and second, the sensors. | 用 physical hand，不用 hardware（hardware 容易被理解成电路板） |
| 进入第一部分 | Let's start with the hand itself. | |
| 介绍实体 | This robotic hand is 3D-printed, and it's built on ORCA Hand, an open-source robotic hand platform. | 不要用 refer to；ORCA 读 "OR-kuh" |
| 演示拇指 | Now I'll make the thumb bend and straighten. | 技术说法：flex and extend |
| 转到第二部分 | That's it for the hand. Now let's move on to the sensors. | |
| 传感器是什么 | This is a six-axis force/torque sensor. It works like a sense of touch for the hand. It measures force in three directions and torque around three axes. | 简称 F/T sensor；axis 读 "AK-sis"，复数 axes 读 "AK-seez" |
| 装在哪 | We plan to put a sensor on each fingertip. | |
| 用来做什么 | It can sense things like grip and slip. It will help the hand detect whether an object is slipping. | 滑动用 slip，不用 slide |
| 意义 | If the object starts to slip, the hand can grip a little tighter. | |
| 不是自己负责的部分 | I'm not in charge of the sensor. [Name] is working on it. | 被追问细节：That's not my area, but I can check with [name] and get back to you. |
| 结尾 | Thank you for listening. Any questions? | |
