# 一根手指：3 个 XC330 弯曲成“抓”的样子

2026-10-23。现在先在桌上模拟（3 个舵机摆在桌上，看舵盘转），手指结构以后再装。控制方式：串口助手发 HEX（经 M7C 面包板转发，和以前一样）。

## 一句话总结

三个关节各给一个目标角度，用**一个 Sync Write 包**同时发出去；再把三个舵机设成**“时间型运动曲线”**，让它们转的角度不同也**同时开始、同时到达**。看起来就是一根手指平滑地弯起来。

## 分工

| ID | 关节 | 舵机 | 伸直 | 握紧（弯曲量） |
| --- | --- | --- | --- | --- |
| 1 | 根部 MCP（掌指关节） | XC330 | 2048 | 3072（+90°） |
| 2 | 中间 PIP（近端指间关节） | XC330 | 2048 | 3072（+90°） |
| 3 | 指尖 DIP（远端指间关节） | XC330（第 3 个，新的） | 2048 | 2731（+60°） |
| 10 | 手腕（以后用） | XC430-T240BB（原来是 ID 3） | — | — |

- 约定：**数值变大 = 弯曲**，2048 = 伸直。一圈 4096，所以 90° = 1024，60° ≈ 683。
- 指尖只弯 60°：人的手指指尖关节弯曲大约是中间关节的 2/3（这是做假手和机械手时常用的经验比例，不是严格规律）。手指装好以后可以按实际结构改。
- 指尖为什么不也弯 90°：真手指握拳时指尖关节弯得最少，三个一样弯会像“钩子”而不像握东西。

---

## 原理：为什么要“时间型运动曲线”

**先猜一下**：出厂设置下（速度型曲线，三个舵机速度一样），发“握紧”这个包：根部转 90°、指尖转 60°。哪个先到？
A. 根部先到　B. 指尖先到　C. 同时到

答案是 **B**。速度一样时，转得少的先到。指尖早早弯完停住，根部还在转，动作看起来一节一节的，很机械。

把三个舵机的 Drive Mode（地址 10）bit 2 设成 1，就是**时间型曲线**：Profile Velocity（地址 112）不再表示速度，而是“**用多少毫秒到达**”；Profile Acceleration（地址 108）是加速、减速各用多少毫秒。三个都设 1000 ms，那么不管各自转多少度，都在 1 秒内同时到达，中间是先加速再减速的平滑曲线。

依据和可信度：
- Drive Mode bit 2 = 时间型曲线、地址 108 的单位有 “1 msec”：出自 XC330-T288 e-Manual 控制表（公认结论）。
- “按指定时间完成动作、与距离无关”：出自 ROBOTIS 官方文章（公认结论）。
- Profile Velocity 在时间型下的单位是 ms、加速时间要小于总时间的一半：按 ROBOTIS X 系列文档的通常说明，但这个舵机的页面我没能读到这一段（较可信，未实测）。**第 3 步就是用眼睛验证它。**

条件：Drive Mode 在 EEPROM 里，**Torque 关着才能写**；写一次断电也不丢。Profile Velocity / Acceleration 在 RAM 里，**每次上电都要重新发**。

## 第 0 步：改 ID（每次总线上只能有一个舵机）

顺序很重要：**先把 XC430 从 3 改成 10，再把新的 XC330 改成 3**。反过来的话，会出现两个 ID 3。

可以用 U2D2 + Wizard（改地址 7），也可以用 M7C 面包板发 HEX。HEX 版：

| # | 总线上只接 | 发送 | 应该收到 |
| --- | --- | --- | --- |
| 0-1 | XC430 | ping 3：`FF FF FD 00 03 03 00 01 1A E6` | 14 字节，型号 `38 04` |
| 0-2 | XC430 | 关扭矩：`FF FF FD 00 03 06 00 03 40 00 00 FD 64` | `FF FF FD 00 03 04 00 55 00 52 8C` |
| 0-3 | XC430 | ID 3 → 10：`FF FF FD 00 03 06 00 03 07 00 0A AD 61` | `FF FF FD 00 03 04 00 55 00 52 8C` |
| 0-4 | XC430 | ping 10：`FF FF FD 00 0A 03 00 01 1A 52` | 14 字节，第 5 个字节 `0A`。贴胶带 “ID 10 手腕” |
| 0-5 | 新 XC330 | ping 1：`FF FF FD 00 01 03 00 01 19 4E` | 14 字节，型号 `C4 04`（或 T181 的 `BA 04`） |
| 0-6 | 新 XC330 | 关扭矩：`FF FF FD 00 01 06 00 03 40 00 00 DE E6` | `FF FF FD 00 01 04 00 55 00 A1 0C` |
| 0-7 | 新 XC330 | ID 1 → 3：`FF FF FD 00 01 06 00 03 07 00 03 B8 E3` | `FF FF FD 00 01 04 00 55 00 A1 0C` |
| 0-8 | 新 XC330 | ping 3：`FF FF FD 00 03 03 00 01 1A E6` | 14 字节，第 5 个字节 `03`。贴胶带 “ID 3 指尖” |

另外两个 XC330 贴上 “ID 1 根部”、“ID 2 中间”。

## 第 1 步：三个 XC330 一起接上

1. PHB 开关关。三个 XC330 接到 PHB（每个直接插 PHB，或两个串一起都可以；三个 XC330 最坏约 2.6A，桌上空转远小于这个）。XC430 这次可以不接。
2. 三个舵机摆在桌上，**舵盘上贴一条胶带当“指节”**，方便看角度。舵盘周围留出空间。
3. 上电：M7C 的 USB → 外部 5V → PHB 开关。
4. 广播 ping：`FF FF FD 00 FE 03 00 01 31 42` → 三个应答共 42 字节，ID 01、02、03。

## 第 2 步：设成时间型曲线（只做一次，Torque 关着）

每条的应答：ID 1 `FF FF FD 00 01 04 00 55 00 A1 0C`，ID 2 `FF FF FD 00 02 04 00 55 00 29 0C`，ID 3 `FF FF FD 00 03 04 00 55 00 52 8C`。

| # | 做什么 | 发送 |
| --- | --- | --- |
| 2-1 | ID 1 关扭矩 | `FF FF FD 00 01 06 00 03 40 00 00 DE E6` |
| 2-2 | ID 2 关扭矩 | `FF FF FD 00 02 06 00 03 40 00 00 EE E5` |
| 2-3 | ID 3 关扭矩 | `FF FF FD 00 03 06 00 03 40 00 00 FD 64` |
| 2-4 | ID 1 Drive Mode = 4（时间型） | `FF FF FD 00 01 06 00 03 0A 00 04 4E E3` |
| 2-5 | ID 2 Drive Mode = 4 | `FF FF FD 00 02 06 00 03 0A 00 04 7E E0` |
| 2-6 | ID 3 Drive Mode = 4 | `FF FF FD 00 03 06 00 03 0A 00 04 6D 61` |
| 2-7 | 确认（读 ID 1 的地址 10） | `FF FF FD 00 01 07 00 02 0A 00 01 00 21 D3` → 应答参数 `04` |

ID 2、3 的确认：`FF FF FD 00 02 07 00 02 0A 00 01 00 2B E3`、`FF FF FD 00 03 07 00 02 0A 00 01 00 2D F3`。

## 第 3 步：每次上电后先发这 9 条（RAM，断电会丢）

| # | 做什么 | 发送 |
| --- | --- | --- |
| 3-1 | ID 1 加减速 300 ms | `FF FF FD 00 01 09 00 03 6C 00 2C 01 00 00 E1 39` |
| 3-2 | ID 1 总时间 1000 ms | `FF FF FD 00 01 09 00 03 70 00 E8 03 00 00 F6 49` |
| 3-3 | ID 2 加减速 300 ms | `FF FF FD 00 02 09 00 03 6C 00 2C 01 00 00 DD 99` |
| 3-4 | ID 2 总时间 1000 ms | `FF FF FD 00 02 09 00 03 70 00 E8 03 00 00 CA E9` |
| 3-5 | ID 3 加减速 300 ms | `FF FF FD 00 03 09 00 03 6C 00 2C 01 00 00 CA 79` |
| 3-6 | ID 3 总时间 1000 ms | `FF FF FD 00 03 09 00 03 70 00 E8 03 00 00 DD 09` |
| 3-7 | ID 1 Torque 开 | `FF FF FD 00 01 06 00 03 40 00 01 DB 66` |
| 3-8 | ID 2 Torque 开 | `FF FF FD 00 02 06 00 03 40 00 01 EB 65` |
| 3-9 | ID 3 Torque 开 | `FF FF FD 00 03 06 00 03 40 00 01 F8 E4` |

想快一点（0.5 秒、加减速 150 ms）就把 3-1～3-6 换成：
ID 1 `FF FF FD 00 01 09 00 03 6C 00 96 00 00 00 C3 71`、`FF FF FD 00 01 09 00 03 70 00 F4 01 00 00 DB 79`；
ID 2 `FF FF FD 00 02 09 00 03 6C 00 96 00 00 00 FF D1`、`FF FF FD 00 02 09 00 03 70 00 F4 01 00 00 E7 D9`；
ID 3 `FF FF FD 00 03 09 00 03 6C 00 96 00 00 00 E8 31`、`FF FF FD 00 03 09 00 03 70 00 F4 01 00 00 F0 39`。

## 第 4 步：认方向（在胶带上画箭头）

数值变大时，舵盘从正面看是**逆时针**转（XC330 出厂是 Normal 模式：CCW 为正）。在桌上模拟时，就把“逆时针”当成“弯曲”。每个舵机单独试一下，在舵盘胶带上画箭头：

| # | 发送 | 应该看到 |
| --- | --- | --- |
| 4-1 | ID 1 → 2048：`FF FF FD 00 01 09 00 03 74 00 00 08 00 00 42 89`，再 → 2304：`FF FF FD 00 01 09 00 03 74 00 00 09 00 00 55 09` | 根部转 22.5°，1 秒内平滑转到 |
| 4-2 | ID 2 → 2048：`FF FF FD 00 02 09 00 03 74 00 00 08 00 00 7E 29`，再 → 2304：`FF FF FD 00 02 09 00 03 74 00 00 09 00 00 69 A9` | 中间转 22.5° |
| 4-3 | ID 3 → 2048：`FF FF FD 00 03 09 00 03 74 00 00 08 00 00 69 C9`，再 → 2304：`FF FF FD 00 03 09 00 03 74 00 00 09 00 00 7E 49` | 指尖转 22.5° |

以后装进真手指时，如果某个舵机装反了（数值变大时手指往外翻），**不用改任何包**：Torque 关着时把它的 Drive Mode 改成 **5**（时间型 + 反向，bit 0 = 1）。ID 1 `FF FF FD 00 01 06 00 03 0A 00 05 4B 63`、ID 2 `FF FF FD 00 02 06 00 03 0A 00 05 7B 60`、ID 3 `FF FF FD 00 03 06 00 03 0A 00 05 68 E1`。反向后读回的位置也跟着反，所以“变大 = 弯曲”对每个关节都成立。注意：反向后伸直位置对应的数值可能会变，装好实物时要重新确认伸直值。

## 第 5 步：手势（每个只发一个包）

全部是 Sync Write，**没有应答是正常的**。每个手势 1 秒内三个关节同时到达。

| 手势 | 根部 / 中间 / 指尖 | 发送 |
| --- | --- | --- |
| **张开**（伸直） | 2048 / 2048 / 2048 | `FF FF FD 00 FE 16 00 83 74 00 04 00 01 00 08 00 00 02 00 08 00 00 03 00 08 00 00 78 4B` |
| **半握** | 2560 / 2560 / 2389（45° / 45° / 30°） | `FF FF FD 00 FE 16 00 83 74 00 04 00 01 00 0A 00 00 02 00 0A 00 00 03 55 09 00 00 7B 10` |
| **握紧** | 3072 / 3072 / 2731（90° / 90° / 60°） | `FF FF FD 00 FE 16 00 83 74 00 04 00 01 00 0C 00 00 02 00 0C 00 00 03 AB 0A 00 00 7D 69` |
| **钩**（像提袋子） | 2048 / 3072 / 2731（根部直，前两节弯） | `FF FF FD 00 FE 16 00 83 74 00 04 00 01 00 08 00 00 02 00 0C 00 00 03 AB 0A 00 00 7B 97` |

**验证时间型曲线**：先发“张开”，等 2 秒，再发“握紧”。三条胶带应该**同时开始、同时停**，指尖转得少所以转得慢。如果指尖明显先停：
1. 读三个的 Drive Mode（第 2 步 2-7），确认是 `04`；
2. 确认第 3 步 3-1～3-6 都发了、都有应答；
3. 还不行，改用下面的“备用做法”，并告诉 Claude。

**备用做法（速度型，按比例设速度）**：Torque 关 → Drive Mode 写回 0（ID 1 `FF FF FD 00 01 06 00 03 0A 00 00 55 63`、ID 2 `FF FF FD 00 02 06 00 03 0A 00 00 65 60`、ID 3 `FF FF FD 00 03 06 00 03 0A 00 00 76 E1`）→ 加速度 0（ID 1 `FF FF FD 00 01 09 00 03 6C 00 00 00 00 00 FA C9`、ID 2 `FF FF FD 00 02 09 00 03 6C 00 00 00 00 00 C6 69`、ID 3 `FF FF FD 00 03 09 00 03 6C 00 00 00 00 00 D1 89`）→ 速度按转角比例：根部、中间 30，指尖 20（= 30 × 60/90）（ID 1 `FF FF FD 00 01 09 00 03 70 00 1E 00 00 00 E2 F1`、ID 2 `FF FF FD 00 02 09 00 03 70 00 1E 00 00 00 DE 51`、ID 3 `FF FF FD 00 03 09 00 03 70 00 14 00 00 00 C9 39`）→ Torque 开。这样只在“张开 ↔ 握紧”之间同时到达；换别的手势比例就不对了，所以时间型更好。

## 第 6 步：两种“抓”的动作

**A. 一起弯（最自然，推荐）**：在串口助手里循环发：握紧 → 等 1.5 秒 → 张开 → 等 1.5 秒。很多串口助手有“多条发送 / 定时循环”功能（比如 SSCOM 的“多字符串”，每条可以设延时），把两条填进去，间隔 1500 ms。

**B. 从根部卷到指尖（像把东西卷进手心）**：依次发，每条间隔约 0.5 秒（不用等前一个动作完全做完，时间重叠会更顺）：

| 顺序 | 根部 / 中间 / 指尖 | 发送 |
| --- | --- | --- |
| B1 | 3072 / 2048 / 2048 | `FF FF FD 00 FE 16 00 83 74 00 04 00 01 00 0C 00 00 02 00 08 00 00 03 00 08 00 00 7E B5` |
| B2 | 3072 / 3072 / 2048 | `FF FF FD 00 FE 16 00 83 74 00 04 00 01 00 0C 00 00 02 00 0C 00 00 03 00 08 00 00 66 F5` |
| B3 | 3072 / 3072 / 2731 | 同“握紧” |
| 松开 | 2048 / 2048 / 2048 | 同“张开” |

为什么 B 能“提前发”：每个舵机收到新目标时，会从**当前位置**重新规划一条 1 秒的曲线，所以前一个动作没做完就发下一个也不会出错，只是动作连在一起了。

**读位置**（看到底转到哪）：`FF FF FD 00 FE 0A 00 82 84 00 04 00 01 02 03 2A 6C` → 三个应答各 15 字节，按 ID 1、2、3 顺序；用 `python tools/dxl_packet.py parse "…"` 解读。

## 第 7 步：结束

张开 → 三个 Torque 关（ID 1 `FF FF FD 00 01 06 00 03 40 00 00 DE E6`、ID 2 `FF FF FD 00 02 06 00 03 40 00 00 EE E5`、ID 3 `FF FF FD 00 03 06 00 03 40 00 00 FD 64`）→ PHB 开关 → 外部 5V → USB。

## 以后装到真手指时（现在不用做）

1. **先设位置限制**（EEPROM，Torque 关着写），让舵机不会把手指掰过头。按上面的伸直/握紧值：
    - 最小值（地址 52）= 2048：ID 1 `FF FF FD 00 01 09 00 03 34 00 00 08 00 00 05 09`、ID 2 `FF FF FD 00 02 09 00 03 34 00 00 08 00 00 39 A9`、ID 3 `FF FF FD 00 03 09 00 03 34 00 00 08 00 00 2E 49`
    - 最大值（地址 48）：ID 1、2 = 3072（`FF FF FD 00 01 09 00 03 30 00 00 0C 00 00 50 69`、`FF FF FD 00 02 09 00 03 30 00 00 0C 00 00 6C C9`），ID 3 = 2731（`FF FF FD 00 03 09 00 03 30 00 AB 0A 00 00 33 35`）
    - 装好以后伸直位置不一定正好是 2048，要先量实际的伸直值再改这些数。
2. **真的抓东西时用“电流限制的位置控制”**（Operating Mode 地址 11 = 5，XC330 支持）。它会限制每个关节用的力（Goal Current，地址 102，单位约 1 mA），手指碰到东西就停在那里、只用设定的力夹住，不会一直硬顶到发热或报过载。这是机械手抓取的主流做法。注意：切换模式会把 Profile 设回 0、重置部分 PID，要重新发第 3 步。

## 风险

| 风险 | 对策 |
| --- | --- |
| 改 ID 顺序反了，出现两个 ID 3 | 先 XC430 3 → 10，再新 XC330 1 → 3 |
| 写 Drive Mode 时 Torque 开着 | 写不进去；先关扭矩（2-1～2-3） |
| 忘了第 3 步（断电后 Profile 变回 0） | Profile Velocity = 0 表示不做曲线、按最快速度转（X 系列文档的说明），会很猛；每次上电先发第 3 步 |
| 舵机在桌上被自己带着转 | 用胶带或夹子把舵机身体固定在桌上，只让舵盘转 |
| `dxl_example3.c` | 那是给 XC330 + XC330 + XC430 写的示例（ID 2 反方向转）。现在 ID 3 是指尖，别用它跑手指，手指用本页的 HEX |
