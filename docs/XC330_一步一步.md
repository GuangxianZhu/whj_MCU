# XC330 12V：一步一步做

配合 [`XC330_12V接入方案.md`](XC330_12V接入方案.md) 使用。那份讲“为什么”，这份讲“手怎么动”。每一步都写了：做什么 → 应该看到什么 → 不对时怎么办。**上一步不对，不要做下一步。**

已确认（2026-10-21）：舵机 XC330-T288-T（12V 版），适配器标签 “12V AKA12050A1”，3P 线两根以上，Dynamixel Wizard 2.0 已装。

---

## 先读：5V 和 12V 同时存在，安不安全？

**结论：只要 12V 那根线（VDD）不碰到 5V 的东西，就是安全的。** 下面分开说。

### 为什么能共存（公认结论）

XC330 内部自己把 12V 降压给它的控制电路用，DATA 线是 **5V 逻辑**（ROBOTIS e-Manual：TTL Multidrop Bus, 5V Logic）。所以：

| 线 | 电压 | 会碰到面包板吗 |
| --- | --- | --- |
| VDD（3P 线 2 号） | 12V | **不能碰**，工作二里包胶带 |
| DATA（3 号） | 0 ↔ 5V | 碰，接第 4 列，和现在 XL330 一样 |
| GND（1 号） | 0V | 碰，接第 2 列，两边必须共地 |

12V 只是舵机电机的“燃料”，进不了信号线。面包板上的 241、TXB 看到的最高还是 5V。

### 真正的隐患（按危险程度排）

1. **XL330 插到 PHB 上**：XL330 是 5V 舵机（工作电压约 3.7–6V），和 XC330 用的是同一种 3P 插头，插得进去。12V 会把它烧坏。→ 做 XC330 实验时，把 XL330 收起来，别放在桌上。
2. **两个适配器拿错**：5V 和 12V 适配器的插头可能长得一样。12V 插进面包板的 5V 端子，241 和 TXB 会立刻坏（241 的 VCC 绝对最大 6.5V）。→ 两个适配器各贴一张胶带，写上 “5V” 和 “12V”。
3. **测量时表笔滑了**：3P 插头的针距只有 2.5mm。量 2 号（12V）的时候笔尖一滑碰到 3 号（DATA），12V 就进了 DATA 线，舵机的通信口可能坏。→ 只在第 1 步、第 B2 步量 12V，量的时候慢一点，用一只手扶稳。
4. **12V 短路发热**：12V 对人没有触电危险（低于安全特低电压）。但 5A 的适配器短路时电流很大，杜邦线会发烫。PHB 官方页面没写有保险丝。多数适配器有短路保护（这是我的推测，你这个型号没查到资料）。→ 接线、拔线前先关 PHB 开关；包了胶带的 VDD 线头不要乱放。
5. **舵机突然转动**：Torque 打开后，舵机会用力转到目标位置。→ 手指离开舵盘，舵机放平稳，不要拿在手里。

### 电压“在 5V 和 12V 之间”会怎样

| 喂给 XC330-T288 的电压 | 结果 |
| --- | --- |
| 低于 5.5V（比如误接 5V） | 不危险，但会报欠压错误（Min Voltage Limit 默认 5.5V），力气很小或不动 |
| 6.5–12.0V | 规格范围，推荐 11.1V |
| 略高于 12V（适配器空载 12.2V 之类） | 稍超规格。实际常见，舵机的过压报警在 14.0V 才触发。量出来以后再判断 |
| 高于 14V | 报过压错误；长期这样可能损坏 |

反过来：XL330 吃 12V 会坏，见隐患 1。

**先猜一下**：XC330 接 12V，它的 DATA 线上最高会出现几伏？
A. 12V　B. 约 5V　C. 3.3V

答案：**B**。12V 只给电机，舵机里面的控制芯片用的是降压后的电压，DATA 是 5V 逻辑。所以面包板不用改。

## 工作一：U2D2 部分

### 第 1 步：量适配器（只插墙上插座，别的都不接）

1. 万用表拨直流电压档（V⎓，手动量程选 20V）。黑笔插 COM 孔，红笔插 V 孔。
2. 适配器插墙上插座。
3. **红笔伸进插头中间的小孔**碰里面的金属，**黑笔碰插头外圈的金属**。两支笔不要互相碰。

| 读数 | 意思 | 下一步 |
| --- | --- | --- |
| +11.8 ～ +12.3V | 中心正，电压正常 | 继续 |
| +12.3V 以上 | 略高 | 记下数字，告诉 Claude 再决定 |
| 带负号（−12V） | 中心是负，PHB 不能用 | 停，换适配器 |
| 0 或乱跳 | 笔没碰到里面 | 换个角度重量 |

4. 拔掉墙上插头。PHB 开关拨到**关**，把插头试插到 PHB 的 DC 口：
    - 插得紧 → 继续
    - 插不进去或很松：插头内径是 2.1mm，PHB 的口是 2.5mm → 改用 PHB 的螺丝端子（左 −、右 +）。这时要用“DC 母座转螺丝端子”的小转接头，接之前用第 1 步的方法量清楚哪根是 +

### 第 2 步：断电接线

**PHB 开关保持关，适配器先不插墙。**

1. 3P 线 A：U2D2 上 **3 针**的口（标 TTL 的那个，不是 4 针的 485 口）→ PHB 上任意一个 3 针口。
2. 3P 线 B：XC330 → PHB 上另一个 3 针口。
3. 插头有方向，插不进去就翻过来，别硬插。
4. U2D2 的 USB 插电脑。
5. 舵机放平稳，舵盘上别挂东西。

**应该看到**：U2D2 上的灯亮（USB 供电）。舵机还不亮，正常。

### 第 3 步：上电，看 LED

1. 适配器插墙，插头插 PHB 的 DC 口（或已经接好的端子）。
2. 打开 PHB 开关。

**应该看到**：XC330 背面的 LED **闪一下**。

不对时：
- 不闪 → 关开关；检查 3P 线 B 两头插到底没有；检查适配器灯（有的话）；重量第 1 步
- 冒烟、有焦味、发烫 → 立刻关开关拔插头，告诉 Claude

### 第 4 步：Wizard 扫描，读电压

1. 先看 COM 口号：Windows 设备管理器 → “ポート（COM と LPT）” → 插拔 U2D2 看哪个出现又消失（一般叫 USB Serial Port (COMx)）。记下 x。
2. 打开 Dynamixel Wizard 2.0 → 上方 **Options**（齿轮）→ Scan 设置：
    - Protocol：只勾 **2.0**
    - Port：只勾刚才的 **COMx**
    - Baudrate：只勾 **57600**
    - ID 范围：0–252（或改成 0–10，扫得快）
3. 点 **Scan**。

**应该看到**：左边列表出现 `[ID:001] XC330-T288`。

不对时：
- 什么都没扫到 → 把 Baudrate 全勾、Protocol 1.0/2.0 都勾再扫一次（万一舵机不是出厂设置）；还不行检查 3P 线 A 有没有插在 U2D2 的 3 针口
- 端口打不开 → 关掉其他占用 COM 口的软件（串口助手）

4. 点左边的舵机，右边出现控制表。找这两行：

| 名称 | 地址 | 应该是 |
| --- | --- | --- |
| Present Input Voltage | 144 | 约 120（单位 0.1V，就是 12.0V），和第 1 步量的差不多 |
| Hardware Error Status | 70 | 0 |

**记下来**：Model Number（应为 1220）、Firmware Version、Present Input Voltage。

### 第 5 步：动一动

1. 控制表里点 **LED**（65），改成 1 → 舵机 LED 常亮；改回 0 → 灭。
2. 右上角把 **Torque** 打开（Torque Enable 64 = 1）。舵机会“咔”地一下锁住，用手转不动了。
3. **Goal Position**（116）输入 1024 → 舵机转过去；再输入 3072 → 转回来。看 **Present Position**（132）跟着变。
4. 把 **Torque** 关掉（64 = 0）。

**应该看到**：每次改完舵机都有反应。

### 第 6 步：串口助手发 ping，记下“标准答案”

这一步是给工作二准备的：以后 M7C 转发的就是同一串字节。

1. Wizard 点 **Disconnect**（不断开的话串口被它占着）。
2. 打开你以前用的串口助手：COMx，57600，8 位数据，无校验，1 位停止位；发送和显示都选 **HEX**。
3. 发送：`FF FF FD 00 01 03 00 01 19 4E`

**应该看到**：收到 14 字节

```
FF FF FD 00 01 07 00 55 00 C4 04 xx CRC CRC
```

- `55` = 这是应答，`00` = 没有错误，`C4 04` = 型号 1220（XC330-T288），`xx` = 固件版本，最后两个字节随固件版本变。
- **把整串 14 字节抄下来或截图**。这就是工作二的“标准答案”。

4. 再发读电压：`FF FF FD 00 01 07 00 02 90 00 02 00 18 91`
    - 应答里 `55 00` 后面的两个字节，低位在前，乘 0.1 就是伏特。比如 `78 00` = 120 = 12.0V。

### 第 7 步：断电收尾

1. 关 PHB 开关 → 拔适配器。
2. 工作一完成，打勾：

- [ ] 适配器 +12V 左右、中心正
- [ ] LED 上电闪一下
- [ ] Wizard 扫到 ID 1、XC330-T288，电压约 12V，错误 0
- [ ] LED、转动都正常
- [ ] 串口助手 ping 的 14 字节已记下

## 工作二：M7C 部分

面包板电路按仓库 `docs/breadboard/README.md` 现状，**一根不改**。

### 第 B1 步：拆 U2D2，准备线

1. PHB 开关关着。
2. 拔掉 3P 线 A（U2D2 ↔ PHB），U2D2 收起来。XC330 留在 PHB 上。
3. 准备一根 **JST EH 3P 转杜邦**的线（一头白色 3P 小插头，另一头 3 根杜邦）。还没有的话：把一根 3P 线从中间剪断，剥线后焊/压杜邦头也行。
4. 3 根线的脚序是：**中间那根是 2 号 VDD（12V）**，两边分别是 1 号 GND 和 3 号 DATA。线的颜色和插头上的标记不一定可靠，B2 步用万用表确认哪边是哪根。
5. 给 3 根杜邦头先贴临时标签，**中间那根（VDD）用胶带包起来**。

### 第 B2 步：只开 PHB，量 3P 线（面包板不接）

1. 3P 线的白色插头插到 PHB 空着的 3 针口。三根杜邦头悬空，互相不碰。
2. 打开 PHB 开关（舵机 LED 闪一下）。
3. 先确认中间那根是 12V：黑笔碰一根边上的线，红笔碰中间那根（撕开一点胶带碰金属，量完马上包回去）。
    - 读数约 +12V → 黑笔碰的这根就是 **1 号 GND**，另一根边上的是 **3 号 DATA**。贴好标签
    - 读数约 0 到几伏 → 黑笔碰的是 DATA，换另一根边上的线再量
4. 黑笔碰 GND，红笔碰 DATA：应该**远低于 12V**（空闲时是几伏的高电平）。
5. 关 PHB 开关。

不对时：DATA 上量到接近 12V，或者中间那根不是 12V → 线序和预想的不一样。停下来，先别接面包板，告诉 Claude。

### 第 B3 步：接面包板

PHB 开关关着。外部 5V、M7C USB 也先断着。

1. **1 号 GND → 2B**（第 2 列，经 P2 到 V1 −）
2. **3 号 DATA → 4B**（第 4 列，DATA 汇合点）
3. **2 号 VDD：不插**，包着胶带放在面包板外面。
4. 原来插在 3B 的舵机 VDD 位置空着，不用动 P3 和 C5。

### 第 B4 步：按顺序上电，量电压

1. M7C 的 USB → 外部 5V → PHB 开关。
2. 量：

| 红笔 | 黑笔 | 应该是 | 不对时 |
| --- | --- | --- | --- |
| V1 + | V1 − | 约 5V | 明显高于 5V → 立刻全部断电，检查 VDD 有没有碰到面包板 |
| 4下 | V1 − | 约 5V（DATA 空闲，R1 上拉） | 0V → DATA 短路到地；查第 4 列 |
| 14下 | V1 − | 约 3.3V | 查 M7C USB |

### 第 B5 步：通信测试

和以前用 XL330 时完全一样：按 `docs/breadboard/快速检查.md`，或者跑 `firmware/dxl/dxl_bench.c` / 转发固件。

1. PC 串口助手（这次是 M7C 的 COM 口）发 ping：`FF FF FD 00 01 03 00 01 19 4E`
2. 收到的 14 字节和工作一第 6 步记下的**完全一样** → 成功。
3. 再发读电压、LED、转动的包（HANDOFF 里的表），确认都正常。

不对时：
- 没应答 → 先查 GND（1 号是不是插在第 2 列）；再按 `快速检查.md` 从头查
- 有回显或 CRC 错误 → 和以前的“坑 2”一样，查共地
- 工作一都通过了，所以问题一定在面包板一侧或接地，不用怀疑舵机

### 第 B6 步：断电

顺序反过来：PHB 开关 → 外部 5V → M7C USB。
