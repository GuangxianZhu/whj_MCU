XL330 面包板接线

PCUSBKM1M7C · 5V↔TXB0104↔74LVC2G241 · 3.3V↔XL330

TXB0104 把 MCU 的 5V 信号转成 3.3V。74LVC2G241 把 TX、RX 两根线合成舵机需要的一根 DATA 线，由 DIR 决定此刻是发送还是接收。PC 只通过 MCU 板的 USB 连接，不需要另外接线。

动手前先看这四条

  1. 带电源轨的面包板：上面红轨 = 5V，下面红轨 = 3.3V，先用胶带写上标注。迷你板没有电源轨，按清单用指定的列当电源。
  2. 两路 5V 不能接在一起。外部 5V 电源只接舵机 VDD；MCU 板的 5V 只接 TXB0104 的 5V 侧。
  3. 所有 GND 必须连在一起：MCU、外部电源、两颗芯片、舵机。
  4. 转接板的 1 脚在左下角（芯片上的圆点那一侧）。如果你的 TXB0104 是成品模块（引脚上印着 VA、VB、A1…），按丝印名字接，列号只作参考。

上电前检查

  1. 接完第 1 组、插芯片之前：万用表打到蜂鸣档，测 5V 对 GND、3.3V 对 GND，都不能响。
  2. 插上 MCU 的 USB，测 5V 处约 5V，3.3V 处约 3.3V。确认后断电。
  3. 接完芯片供电后再上电：TXB0104 第 1 脚 3.3V、第 14 脚 5V，74LVC2G241 第 8 脚 3.3V。
  4. 舵机先别插。接通外部电源，测第 39 列对第 40 列约 5V。
  5. 全部接好后的上电顺序：先插 MCU 的 USB，再开外部 5V。断电顺序相反。
  6. 舵机上电时 LED 会闪一下，说明供电正常。

转接板要和芯片封装匹配。74LVC2G241 有 DCU（VSSOP，0.5mm 间距）和 DCT（SM8，0.65mm 间距）两种，买之前看清芯片型号后缀。迷你板布局很紧，转接板的针脚最好是 0.3 英寸（7.62mm）行距。

软件要点

XL330 出厂设置：ID 1，波特率 57600，Protocol 2.0。

发送一包指令的顺序：DIR 置 1 → 写完所有字节 → 等到 UART 的“发送完成”标志（不是“发送缓冲空”）→ DIR 置 0 → 接收舵机应答。DIR 切得太早会截断最后一个字节，切得太晚会丢掉应答的开头。

发送期间 1Y 是关闭的，MCU 的 RX 收不到自己发出的数据，不会有回显。

三个电阻的作用

R1 10k：收发切换的瞬间没人驱动 DATA，上拉让它保持空闲的高电平。

R2 100k：发送时 1Y 关闭，RX 线悬空，上拉让 MCU 读到的是空闲状态而不是噪声。

R3 100k：MCU 复位或还没初始化时，DIR 默认为低，241 保持接收，不会去抢总线。

TXB0104 要求它两侧的上下拉电阻不小于 50kΩ，所以 R2、R3 用 100k。R1 在 241 一侧，不受这个限制。

电源方案

当前方案：MCU 板由 USB 供电，它的 5V、3.3V 引脚作为输出给面包板；外部 5V 只给舵机。

改用外部 5V 给逻辑也可以：外部 5V 同时给舵机和 TXB0104 的 5V 侧，但 MCU 的 5V 脚就不能再接进来。同一条电源线上只能有一个电源，两个 5V 并在一起会互相倒灌，可能损坏电脑的 USB 口。

更简单的接法：ROBOTIS 的资料说明 XL330 的 DATA 能耐受 5V TTL，74LVC2G241 也支持 5V 供电。所以也可以去掉 TXB0104，把 241 的 VCC 和 R1 都接 5V，MCU 的 TX、RX、DIR 直接接 241。保留 TXB0104 的好处是总线一侧是 3.3V，演示电平转换更直观。
