4 步、18 项，不用改程序：DIR 用你现有的 DIR 口手动切换，数据从 PC 用 HEX 手动发。第 2 步拔掉 S7 做回环，一次测完 MCU 到 241 的整条通路；只有它不通过，才做第 3 步逐段定位。只有最后的 4.3（收舵机应答）需要程序自动切 DIR。填入读数或点选结果，页面自动判断。

4.3

要加的程序

舵机收到包约 0.5ms 后就回答，DIR 必须在这之前回到 0，所以只能由程序做。在 MCU 把 PC 的数据转给舵机的地方加三处。PC 一个包的字节是陆续到的，所以用“隔 2ms 没有新字节”判断一个包发完。

/* 收到 PC 的字节，准备转给舵机 */
if (!sending) { DIR = 1; sending = 1; }   /* 1. 第一个字节前切到发送 */
uart_servo_write(byte);
last_byte_time = now_ms();

/* 主循环里一直检查 */
if (sending && now_ms() - last_byte_time >= 2 && uart_servo_tx_complete()) {
    DIR = 0;                                /* 2. 发完（TC 置位）立刻切回接收 */
    sending = 0;
}
/* 3. 舵机串口收到的字节原样转给 PC */
