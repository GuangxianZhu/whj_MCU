# 阶段 1：单关节试验台（ID 3，一个舵机带两根线）

2026-10-25 定下：一个关节，ID 3 的 XC330，舵盘上装卷线轮，两根线反向绕在上面。舵机往一边转，**屈线**（拉弯的线）卷进来、**伸线**（拉直的线）放出去，手指弯曲；往另一边转，手指伸直。
这一阶段的目标：**确认这一节能平稳地弯、能平稳地伸直，换方向时不空转，力气有上限**，并且记下这一节的数据，留给后面用。

先看路线图 [`路线图_腱绳手指.md`](路线图_腱绳手指.md) 里的 5 个概念。本页所有数据包都由 `tools/dxl_packet.py` 生成（脚本 `tools/gen_stage1_doc.py`），不是手算的。
每条写入的正常应答都是 `FF FF FD 00 03 04 00 55 00 52 8C`。

## 整体顺序

| 步 | 做什么 | 为什么 |
| --- | --- | --- |
| 1 | 量两个半径，算传动比 | 知道舵机转多少，关节才转 90° |
| 2 | 断电，用手转，检查机械 | 先确认线绕对了、不打滑，再让电机出力 |
| 3 | 设成限力模式（模式 5） | 出错时力气有上限，线和手指不会被拉坏 |
| 4 | **用手扳**手指，读出“伸直”和“弯曲”两个位置 | 舵机不知道自己装在手指上，这两个数要你量出来 |
| 5 | 让舵机小步动 | 确认方向对、动作顺 |
| 6 | 调预紧、查空转 | 两根线不能太松也不能太紧 |
| 7 | 限力试抓一个软东西 | 确认碰到东西会停，不会硬顶 |
| 8 | 来回 10 次，检查 | 确认能重复，线结不滑 |
| 9 | 填数据表 | 阶段 2、3 要用 |

---

## 第 1 步：量两个半径，算传动比

用尺子或卡尺量（单位 mm）：

- **r_s**：卷线轮上线绕的地方的半径（槽底到中心）。
- **r_j**：手指关节处，线到关节转轴中心的距离（关节上有滑轮就量滑轮半径，没有滑轮就量线经过的孔到转轴的距离）。

```
关节转角 = 舵机转角 × r_s ÷ r_j
关节转 90° 需要舵机转 = 90° × r_j ÷ r_s
换成位置数值 = 1024 × r_j ÷ r_s      （一圈 4096，90° = 1024）
```

例：r_s = 10 mm，r_j = 5 mm → 关节转 90° 只要舵机转 45°，也就是位置变化约 512。

这个数先记下来，第 4 步实际量出来以后对照：差得太多，说明线在打滑，或者有一段松线。

## 第 2 步：断电，用手转，检查机械

PHB 开关**关着**，舵机不通电，用手慢慢转舵盘：

| 检查 | 应该是 | 不对时 |
| --- | --- | --- |
| 往一个方向转 | 手指平滑地弯曲 | 卡住：看线有没有卡在边缘或孔里 |
| 往反方向转 | 手指平滑地伸直 | 伸不直：伸线太松，或者绕的方向不对 |
| 两根线 | 都是直的，没有明显耷拉的一段 | 有一根松：重新绕紧（预紧），见第 6 步 |
| 线在卷线轮上 | 待在槽里，不打滑、不叠成一团、不掉出槽 | 打滑：线头要打结固定在卷线轮上 |
| 手感 | 整个过程阻力差不多均匀 | 某处特别紧：那里摩擦大，检查走线 |

两根线都是从卷线轮的固定点出发，所以**来回转的总角度不要超过半圈太多**，否则线会绕到对方的线上去。

## 第 3 步：设成限力模式（Torque 关着）

上电：M7C 的 USB → 外部 5V → PHB 开关。**这一阶段总线上只接 ID 3**，其他舵机先拔掉，最不容易混。

| # | 做什么 | 发送 | 应该收到 |
| --- | --- | --- | --- |
| 3-1 | ping 3 | `FF FF FD 00 03 03 00 01 1A E6` | 14 字节，型号 `C4 04`（XC330-T288） |
| 3-2 | Torque 关 | `FF FF FD 00 03 06 00 03 40 00 00 FD 64` | 写入应答 |
| 3-3 | Operating Mode = 5（电流限制位置控制） | `FF FF FD 00 03 06 00 03 0B 00 05 7F 61` | 写入应答 |
| 3-4 | 确认模式 | `FF FF FD 00 03 07 00 02 0B 00 01 00 2E 67` | 参数 `05` |
| 3-5 | Drive Mode = 0（正常方向，速度型曲线） | `FF FF FD 00 03 06 00 03 0A 00 00 76 E1` | 写入应答 |
| 3-6 | 力气上限 Goal Current = 60 mA | `FF FF FD 00 03 07 00 03 66 00 3C 00 44 8D` | 写入应答 |
| 3-7 | 慢速 Profile Velocity = 20（约 4.6 rpm） | `FF FF FD 00 03 09 00 03 70 00 14 00 00 00 C9 39` | 写入应答 |
| 3-8 | Profile Acceleration = 0 | `FF FF FD 00 03 09 00 03 6C 00 00 00 00 00 D1 89` | 写入应答 |

- 3-3、3-5 存在 EEPROM，写一次断电也不丢；**3-6～3-8 存在 RAM，每次上电都要重发**。
- 3-6～3-8 一定放在 3-3 后面：切换模式会把 Profile 清零（e-Manual）。
- 读电流的方法：发 `FF FF FD 00 03 07 00 02 7E 00 02 00 39 69`，应答里 `55 00` 后面 2 个字节，低位在前，单位 mA。例：`3C 00` = 60 mA，`C4 FF` = −60 mA（负号 = 往反方向用力）。XC330 测的是整个舵机的输入电流，所以不用力时也有一点读数。

## 第 4 步：用手扳，读出“伸直”和“弯曲”两个位置

**先猜一下**：Torque 关着（舵机不用力），你用手扳手指，舵机读到的位置会变吗？
A. 会，角度传感器一直在工作
B. 不会，Torque 关了就什么都不工作

答案是 **A**。Torque 只管电机出不出力，角度传感器只要有电就一直在读。所以可以用手把手指摆到想要的样子，再读舵机的位置。这就是**校准**，比让电机自己乱转安全得多。

| # | 做什么 | 发送 | 记下 |
| --- | --- | --- | --- |
| 4-1 | 确认 Torque 关着 | `FF FF FD 00 03 06 00 03 40 00 00 FD 64` | |
| 4-2 | 用手把手指扳到**伸直**（伸线刚好拉紧），扶住不动，读位置 | `FF FF FD 00 03 07 00 02 84 00 04 00 11 35` | **P_open** = ____ |
| 4-3 | 用手把手指扳到**弯到你想要的程度**（不是硬顶到底），扶住，读位置 | `FF FF FD 00 03 07 00 02 84 00 04 00 11 35` | **P_close** = ____ |

读出来的应答用 `python tools/dxl_packet.py parse "…"` 解读，它会把位置打印成十进制。不方便运行的话，把收到的 HEX 发给 Claude。

接下来判断三件事：

1. **方向**：P_close 比 P_open **大** → 正常，继续。P_close 比 P_open **小** → 让它反过来，以后统一“数值变大 = 弯曲”：Torque 关着发 `FF FF FD 00 03 06 00 03 0A 00 01 73 61`（Drive Mode = 1，反向），然后重做 4-2、4-3。
2. **范围**：P_close − P_open 和第 1 步算的“1024 × r_j ÷ r_s”（按你实际弯的角度换算）差不多吗？差很多 → 线在打滑或有松线，回第 2 步。
3. **跨零点**：如果两个数一个很大（接近 4095）、一个很小（接近 0），说明正好跨过了一圈的接缝。这时把卷线轮在舵盘上的安装角度转一个位置，或者把数发给 Claude 处理。

## 第 5 步：小步动

用第 4 步的两个数，算出 5 个目标：

| 目标 | 数值 |
| --- | --- |
| T0 = P_open | |
| T1 = P_open + (P_close − P_open) × 1/4 | |
| T2 = 一半 | |
| T3 = 3/4 | |
| T4 = P_close | |

每个目标的包用 `python tools/dxl_packet.py goal 3 数值` 生成，或者查文末的表取最近的值，或者把 P_open、P_close 发给 Claude，直接生成这一组包。

| # | 做什么 | 发送 / 看什么 |
| --- | --- | --- |
| 5-1 | Torque 开（舵机就停在当前位置） | `FF FF FD 00 03 06 00 03 40 00 01 F8 E4` |
| 5-2 | 去 T0（伸直） | 手指伸直 |
| 5-3 | 依次去 T1 → T2 → T3 → T4，每步等 2 秒 | 手指一点点弯；每步读位置 `FF FF FD 00 03 07 00 02 84 00 04 00 11 35` 和电流 `FF FF FD 00 03 07 00 02 7E 00 02 00 39 69`，填进第 9 步的表 |
| 5-4 | 反过来 T4 → T3 → T2 → T1 → T0 | 手指一点点伸直 |

这一步只有 60 mA 的力气，如果某一步舵机明显追不上目标（实际位置和目标差 50 以上），说明那里阻力大（摩擦或卡住），先别加电流，检查机械。

## 第 6 步：调预紧、查空转

| 检查 | 怎么做 | 判断 |
| --- | --- | --- |
| 空转（回差） | 停在 T2，发 T2 + 64，再发 T2 − 64，眼睛盯着手指 | 两次手指都**马上**跟着动 → 好；舵机转了手指却等一下才动 → 线太松 |
| 太松 | 停在 T2，用手轻轻往两边推指尖 | 能晃动一段才有阻力 → 太松 |
| 太紧 | 比较“装线前”和“装线后”停在 T2 时的电流 | 装线后电流大很多，或者来回走时舵机吃力、发热 → 太紧 |

太松：把一根线在卷线轮上多绕一点再固定；太紧：放一点。调完重做第 4 步（P_open、P_close 会变）。
“大很多”没有精确标准，这是经验判断：先记下数字，阶段 2 再定。

## 第 7 步：限力试抓一个软东西

在手指弯曲的路径上放一块海绵（或卷起来的纸）。

| # | 做什么 | 看什么 |
| --- | --- | --- |
| 7-1 | Goal Current = 60 mA：`FF FF FD 00 03 07 00 03 66 00 3C 00 44 8D`，去 T4 | 手指碰到海绵就停住、轻轻压着；读位置：停在 T4 之前；读电流：接近 60 mA |
| 7-2 | 回 T0 | 松开 |
| 7-3 | 改成 100 mA：`FF FF FD 00 03 07 00 03 66 00 64 00 42 5D`，再去 T4 | 海绵被压得更深一点 |
| 7-4 | 回 T0；需要再大就改成 150 mA：`FF FF FD 00 03 07 00 03 66 00 96 00 4E 71` | |

这就是模式 5 的意义：**目标照样是“弯到底”，但力气到上限就停在那里**。判断“抓到了”的办法：位置停在目标之前，同时电流到了上限。

## 第 8 步：来回 10 次，检查

在串口助手的多条发送里放两条：去 T4、去 T0，间隔 3 秒，循环 10 次。然后检查：

| 检查 | 发送 | 合格 |
| --- | --- | --- |
| 每次到 T4 的位置 | `FF FF FD 00 03 07 00 02 84 00 04 00 11 35` | 每次差不多 |
| 线结、线在卷线轮上的位置 | 事先用笔在线上和卷线轮上各画一个记号 | 记号没错开 |
| 温度 | `FF FF FD 00 03 07 00 02 92 00 01 00 17 13`（参数就是 °C） | 远低于 70 °C |
| 报错 | `FF FF FD 00 03 07 00 02 46 00 01 00 30 83` | `00` |

有报错（不是 `00`，或者 Torque 自己关了）：多半是过载。发重启 `FF FF FD 00 03 03 00 08 2C E6`，然后重发第 3 步的 3-6～3-8，降低电流或者减小弯曲量。

结束：回 T0 → Torque 关 `FF FF FD 00 03 06 00 03 40 00 00 FD 64` → PHB 开关 → 外部 5V → USB。

## 两个要记住的地方

- **断电或重启后，位置会回到一圈以内**（模式 5 的说明，e-Manual）。卷线轮来回不到一圈时通常没影响，但每次上电先读一次位置，确认和 P_open、P_close 对得上。
- **位置限制（地址 48/52）在模式 5 下不一定生效**（e-Manual 没写清楚），所以不要依赖它；安全靠 Goal Current 限力，以及只发 T0～T4 之间的目标。
