# 固件流程图

三张图：`main()` 整体怎么跑、一次收发（`dxl_txrx`）里面做了什么、以及你现在“PC 手动发、MCU 转发”的程序加上自动切 DIR 以后的样子。图里的函数名和 `firmware/dxl/` 里的代码一一对应。

## 1. main()：上电到舵机来回转

`main()` 做完初始化后调用 `dxl_example_run()`（`dxl_example.c`）。

```mermaid
flowchart TD
    A(["上电"]) --> B["初始化时钟"]
    B --> C["UART 初始化<br/>57600 bps，8N1"]
    C --> D["DIR 引脚设为输出，先写 0<br/>（241 处于接收）"]
    D --> E["dxl_example_run()"]
    E --> F["dxl_ping(ID 1)"]
    F --> G{"返回 DXL_OK？"}
    G -- "否" --> H["打印错误原因<br/>等 500 ms"]
    H --> F
    G -- "是" --> I["打印型号<br/>1200 = XL330-M288"]
    I --> J["LED 亮 → 等 300 ms → LED 灭 → 等 300 ms<br/>重复 3 次"]
    J --> K["打开扭矩<br/>写地址 64 = 1"]
    K --> L["写目标位置<br/>地址 116，1024 和 3072 交替"]
    L --> M["等 1 秒"]
    M --> N["读当前位置<br/>地址 132"]
    N --> O["打印目标和当前位置"]
    O --> L
```

## 2. 一次收发：dxl_txrx()

`dxl_ping`、`dxl_set_led`、`dxl_set_goal_position`、`dxl_get_present_position` 最后都走这个函数（`dxl.c`）。DIR 的切换就在这里。

```mermaid
flowchart TD
    A(["dxl_txrx(ID, 指令, 参数)"]) --> B["组包<br/>包头 FF FF FD 00、ID、长度、指令、参数<br/>字节填充 + CRC16"]
    B --> C["清空接收缓冲"]
    C --> D["DIR = 1<br/>241 打开发送，关闭接收"]
    D --> E["把整个包写进 UART"]
    E --> F["等“发送完成”（TC）<br/>不是“发送缓冲空”（TXE）"]
    F --> G["DIR = 0<br/>241 回到接收"]
    G --> H{"ID 是广播 FE？"}
    H -- "是" --> OK1(["返回 OK<br/>广播不等应答"])
    H -- "否" --> I["找包头 FF FF FD 00<br/>舵机约 0.5 ms 后开始回答"]
    I --> T1{"超时？"}
    T1 -- "是" --> ET(["返回 TIMEOUT"])
    T1 -- "否" --> J["读 ID、长度"]
    J --> K{"长度合法？"}
    K -- "否" --> EF(["返回 FORMAT"])
    K -- "是" --> L["按长度读完剩下的字节"]
    L --> T2{"超时？"}
    T2 -- "是" --> ET
    T2 -- "否" --> M{"CRC 对？"}
    M -- "否" --> EC(["返回 CRC"])
    M -- "是" --> N{"指令是 55（应答包）？"}
    N -- "否" --> EF
    N -- "是" --> P{"ID 和发出去的一样？"}
    P -- "否" --> EI(["返回 ID"])
    P -- "是" --> Q["去掉字节填充，取出参数"]
    Q --> R{"错误字节是 0？"}
    R -- "否" --> ES(["返回 STATUS<br/>舵机报告了错误"])
    R -- "是" --> OK2(["返回 OK"])
```

返回值：`DXL_OK` = 0，`TIMEOUT` = -1，`CRC` = -2，`ID` = -3，`STATUS` = -4，`FORMAT` = -6。

## 3. 你现在的程序：PC 手动发，MCU 转发（加上自动切 DIR）

PC 串口助手用 HEX 发一个包，MCU 把它转给舵机，再把舵机的应答转回 PC。手动切 DIR 来不及收应答（舵机约 0.5 ms 就回答），所以要按下面这样由程序自动切。对应 `docs/breadboard/快速检查.md` 的 4.3。

```mermaid
flowchart TD
    A(["主循环"]) --> B{"PC 串口收到字节？"}
    B -- "是" --> C{"sending = 0？<br/>（这是包的第一个字节）"}
    C -- "是" --> D["DIR = 1，sending = 1"]
    C -- "否" --> E
    D --> E["把这个字节写进舵机串口<br/>记下时间 last_byte_time"]
    E --> A
    B -- "否" --> F{"sending = 1<br/>且 2 ms 没有新字节<br/>且发送完成（TC）？"}
    F -- "是" --> G["DIR = 0，sending = 0<br/>回到接收，等舵机应答"]
    G --> A
    F -- "否" --> H{"舵机串口收到字节？"}
    H -- "是" --> I["原样转给 PC"]
    I --> A
    H -- "否" --> A
```
